# 📋 GOST Search App: Интеллектуальная система семантического поиска по техническим стандартам (ГОСТ)

Прикладное Enterprise-ready MVP решение для автоматизации работы инженерных и проектных отделов. Система позволяет осуществлять умный семантический (по смыслу) поиск по тяжелым массивам нормативно-технической документации и ГОСТам, минимизируя время на поиск регламентов при проектировании оборудования.

В основе проекта лежит архитектура **RAG (Retrieval-Augmented Generation)** с использованием локальных моделей эмбеддингов и облачной векторной базы данных.

---

## 🚀 Ключевые особенности и ИИ-архитектура

В отличие от классического поиска по ключевым словам, система понимает инженерный контекст и синонимы благодаря семантическому анализу:

1. **Парсинг и Чанкинг со сдвигом:** Модуль обработки PDF-документов разбивает сложные тексты стандартов на смысловые абзацы (чанки) с контролируемым перекрытием (overlap), чтобы не терять контекст и логические связи на стыках страниц.
2. **Локальная векторизация (On-Premise Embeddings):** Для превращения текста в математические векторы используется локальная модель `all-MiniLM-L6-v2`. Это гарантирует базовую конфиденциальность данных, так как индексация текста происходит локально без отправки сырых документов на внешние API.
3. **Облачный векторный индекс:** Сгенерированные «координаты смысла» (эмбеддинги) передаются и хранятся в специализированной базе данных `Qdrant Cloud`, где развернут быстрый поиск по косинусному сходству.
4. **Контекстный ответ (Synthesis):** Выбранные релевантные куски документов передаются в генеративную модель (LLM) для формирования краткой и точной выжимки по запросу пользователя.

## 🛠 Стек технологий

* **Язык разработки:** Python 3.11+
* **Векторизация текста:** Sentence-Transformers (`all-MiniLM-L6-v2`)
* **Векторная база данных:** Qdrant Cloud (семантический поиск, векторизация запросов)
* **Локальное структурирование:** SQLite (хранение метаданных, ID документов и связей)
* **Интерфейс системы:** Streamlit Web UI
* **Парсинг документов:** PyPDF2
* **Среда развертывания:** Replit

## 📈 Возможные точки роста (Перспективы развития проекта)

Текущая версия является рабочим прототипом. Для масштабирования системы до уровня промышленного enterprise-решения выделены следующие шаги:
* **Внедрение OCR-модуля (Tesseract / EasyOCR):** Интеграция оптического распознавания символов для обработки старых сканированных ГОСТов и чертежей, сохраненных в виде картинок внутри PDF, что сейчас является главным ограничением базовых текстовых парсеров.
* **Переход на двуязычную/русскоязычную модель эмбеддингов:** Замена `all-MiniLM` на специализированную модель (например, `rubert-tiny` или аналогичные от Яндекс/Сбер), оптимизированную под глубокую техническую терминологию на русском языке, для повышения точности семантического поиска.
* **Интеграция с PDM/PLM системами предприятия:** Подключение поискового движка напрямую к внутренним архивам проектных институтов и заводов для сквозного поиска по внутренним ТУ (техническим условиям) и чертежам компании.

## 💻 Инструкция по локальному развертыванию

Выполните последовательно следующие команды в терминале вашей ОС:

### 1. Клонирование и подготовка окружения
```bash
# Клонирование репозитория
git clone https://github.com/Aygren/gost-search-app.git
cd gost-search-app

# Создание и активация виртуального окружения
python -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка секретов
Для работы приложения необходимы ключи доступа к Qdrant Cloud и выбранной LLM. Настройте их в переменных окружения вашей среды (или в панели Secrets на Replit):
* `QDRANT_HOST` — URL вашего кластера в Qdrant Cloud
* `QDRANT_API_KEY` — Ключ доступа к векторной базе
* `OPENAI_API_KEY` — API-ключ для генеративной модели (при использовании внешнего провайдера)

### 3. Локальный запуск
```bash
streamlit run app.py
```
