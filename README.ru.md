# 🚘 PDD AI Assistant: Мультиплатформенная ИИ-экосистема Автоюриста

[Read in English](README.md)

Интеллектуальный ИИ-помощник для экспресс-анализа обстоятельств ДТП и автоматизированной юридической консультации на основе актуальных Правил дорожного движения РФ. 

Проект разработан в рамках курсового задания платформы Stepik и представляет собой распределенную экосистему, состоящую из веб-интерфейса и Telegram-бота с поддержкой распознавания голосового ввода (STT).

## 🔥 Ключевая особенность и ИИ-архитектура

В отличие от базовых RAG-систем (простого поиска по документам), в проекте реализован продвинутый паттерн **Information Gathering Agent (Квалифицирующий агент)**, имитирующий опрос у реального адвоката:

1. **Многоэтапный JSON-анализ:** Первичная модель-аналитик исследует контекст ситуации и валидирует её по чек-листу ГИБДД (направление движения, знаки приоритета, статус светофоров).
2. **Дорожная логика:** ИИ умеет распознавать специфичные типы аварий (например, наезды сзади, попутные столкновения) или работу светофоров на регулируемых перекрестках, автоматически адаптируя сценарий опроса и снижая требования к водителю в стрессовой ситуации.
3. **Удерживание контекста и допрос:** Если данных для вынесения вердикта недостаточно, агент генерирует точечные уточняющие вопросы, удерживая сессию общения.
4. **Гибридный Полнотекстовый RAG:** Только после сбора 100% необходимых фактов (или по истечении 2-х кругов диалога) запускается поисковый оптимизатор, который извлекает релевантные статьи ПДД из базы данных для финального юридического разбора.

## 🛠 Стек технологий

* **Язык разработки:** Python 3.12
* **Оркестрация и ИИ-цепочки:** LangChain (с управлением контекстом через `InMemoryChatMessageHistory`)
* **Модели ИИ (Мозг системы):** Mistral AI (`mistral-small-latest`) с тонкой настройкой гибридного вывода (свободный текст + строгий JSON-mode)
* **Распознавание речи (STT):** Groq API (`whisper-large-v3`) — субсекундная транскрибация аудиобайтов
* **База знаний и Поиск:** Supabase (PostgreSQL). Продвинутый лингвистический полнотекстовый поиск (`tsvector`/`tsquery`) с автоматической генерацией лексем с учетом русской морфологии.
* **Интерфейсы системы:** Streamlit (Веб-фронтенд) и pyTelegramBotAPI (Телеграм-интерфейс)

## 🚀 Инструкция по локальному развертыванию

Выполните последовательно следующие команды в терминале вашей ОС:

### 1. Клонирование и подготовка окружения
~~~bash
# Клонирование репозитория
git clone https://github.com/Aygren/pdd-ai-assistant.git
cd pdd-ai-assistant

# Создание и активация виртуального окружения
python -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
~~~

### 2. Настройка Базы Данных (Supabase & Full-Text Search)
Проект использует встроенные лингвистический возможности PostgreSQL для поиска по правилам дорожного движения.
1. Создайте новый проект в **Supabase**.
2. Откройте встроенный **SQL Editor** в панели управления Supabase.
3. Скопируйте и выполните содержимое скрипта из файла **[supabase/migrations.sql](supabase/migrations.sql)**. Это создаст таблицы, GIN-индексов и поисковую функцию с морфологией.
4. Запустите скрипт для первоначального наполнения базы данных чанками ПДД:
~~~bash
python -m src.upload_to_supabase
~~~

### 3. Настройка переменных окружения
Создайте файл `.env` в корневой директории проекта и укажите ваши API-ключи:
~~~ini
MISTRAL_API_KEY=your_mistral_api_key_here
GROQ_API_KEY=your_groq_api_key_for_whisper
SUPABASE_URL=your_supabase_project_url_here
SUPABASE_KEY=your_supabase_anon_public_key_here
TG_BOT_TOKEN=your_telegram_bot_token_from_botfather
~~~

### 4. Локальный запуск компонентов

* **Запуск Веб-сайта:**
~~~bash
streamlit run app.py
~~~
* **Запуск Telegram-бота:**
~~~bash
python -m src.tg_bot
~~~

## ☁️ Архитектура облачного деплоя (Production)

Система спроектирована как распределенный сервис с общим бэкендом:

1. **Веб-интерфейс (Streamlit Cloud):** Развернут на платформе Streamlit Cloud, синхронизирован с веткой `main`. Переменные окружения изолированы в Advanced Settings платформы.
2. **Telegram-бот (Render.com):** Развернут как фоновый Web Service на Render. Авто-деплой отключен для контроля версий разработчиком.
   * **Build Command:** `pip install -r requirements.txt`
   * **Start Command:** `python -m http.server $PORT > /dev/null & python -m src.tg_bot`
3. **Оптимизация доступности (Cron-Job.org):** Для предотвращения "засыпания" бесплатного контейнера Render настроен внешний планировщик, отправляющий пинг-запросы на веб-порт приложения каждые 15 минут.

## 🚀 Перспективы развития проекта
На основе анализа работы текущего MVP выделены следующие направления для развития:
* **Кнопка «Вызов автоюриста»:** интеграция перевода пользователя на реального специалиста в сложных ситуациях, где модель упирается в логические ограничения (например, динамические приоритеты дорог).
* **Интеграция под автошколы (B2B):** адаптация ассистента в качестве интерактивного ИИ-репетитора для помощи ученикам при подготовке к теоретическому экзамену ГИБДД.
* **Дополнительные сервисы по API:** подключение шлюзов для проверки штрафов или расчета стоимости ОСАГО прямо внутри диалога.
